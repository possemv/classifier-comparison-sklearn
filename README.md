# Classifier Comparison – scikit-learn

Comparison of KNN, Decision Tree, Random Forest and SVM 
on 3 datasets: Wine, California Housing, SMS Spam.

## Technologies
Python, scikit-learn, pandas, matplotlib, seaborn

## Results
- Wine: Random Forest ~99% accuracy
- Housing: Random Forest best F1
- Spam: SVM best F1 (high-dimensional TF-IDF)
